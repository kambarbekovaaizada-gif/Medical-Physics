# Медициналық физика

10–11-сынып оқушыларына арналған «Медициналық физика» элективті курсының интерактивті оқу сайты. Жоба физикалық құбылыстардың медицинада қолданылуын теория, есептер, тесттер және виртуалды тәжірибелер арқылы түсіндіреді.

## Курстың мазмұны

Курс бағдарламасы 34 академиялық сағатқа арналған. Осы нұсқада 1–8-сабақтардың оқу материалдары мен интерактивті бөлімдері енгізілген. 9–34-сабақтар бағдарламада көрсетілген, толық материалдары әлі қосылмаған.

| № | Қолжетімді сабақ |
|---|---|
| 1 | Медициналық физикаға кіріспе |
| 2 | Медициналық физиканың дамуы және заманауи медициналық технологиялар |
| 3 | Қысым және оны медицинада өлшеу |
| 4 | Қан ағысының физикалық негіздері және Бернулли заңы |
| 5 | Сұйықтықтардың тұтқырлығы және медициналық технологиялар |
| 6 | Газ заңдары және тыныс алу техникасы |
| 7 | Өкпені жасанды желдету аппараттары |
| 8 | Дыбыс толқындары және олардың қасиеттері |

## Мүмкіндіктері

- Курстың сипаттамасы және 34 сабақтың бағдарламасы.
- Сабақ мақсаты, күтілетін нәтижелер, теория, формулалар және иллюстрациялар.
- Деңгейлік есептер мен өмірлік жағдаяттарға негізделген тапсырмалар.
- Жауаптарды тексеретін тесттер.
- Параметрлерін өзгертуге болатын виртуалды тәжірибелер.
- Қазақша, орысша және ағылшынша интерфейс пен курс бағдарламасы.
- Компьютер мен мобильді құрылғыларға бейімделген дизайн.

**Тілдер:** сабақтардың толық мазмұны осы нұсқада орыс тілінде берілген. Қазақша және ағылшынша режимдерде тиісті ескерту көрсетіледі.

## Виртуалды зертхана

1. Жүрек жиырылуының жиілігі мен периоды.
2. Цифрлық визуализация.
3. Манжета орнының қысымға әсері.
4. Қан ағысы және Бернулли заңы.
5. Тұтқырлық және сұйықтық шығыны.
6. Газ заңдары: изотермиялық процесс.
7. Өкпені желдету: созылғыштық пен кедергі.
8. Дыбыстың жиілігі, периоды және толқын ұзындығы.

Модельдер оқу мақсатында жасалған; олар медициналық диагностика жүргізуге арналмаған.

## Іске қосу

`index.html` файлын жүктеп алып, заманауи браузерде ашыңыз. Сайттың коды, оқу деректері және иллюстрациялары бір файлға енгізілген. Негізгі жұмысы үшін сервер, дерекқор, пакет орнату немесе сыртқы API қажет емес.

Қажет болса, Python орнатылған компьютерде жоба орналасқан бумада жергілікті серверді іске қосуға болады:

```bash
python -m http.server 8000
```

Содан кейін браузерде `http://localhost:8000` мекенжайын ашыңыз.

## Қолданылған технологиялар

HTML5, CSS3, JavaScript, Canvas, SVG және браузердің `localStorage` сақтау механизмі. Бөлімдер арасында ауысу URL хештері арқылы орындалады: `#home`, `#about`, `#lessons`, `#lesson/1`, `#tasks/1`, `#lab/1`, `#quiz/1`.

## Деректерді сақтау және шектеулер

Таңдалған тіл, қаралған сабақ белгілері және жіберілген жауаптар осы браузердің `localStorage` жадында сақталады. Олар басқа құрылғыларға автоматты түрде көшірілмейді. Браузердің сайт деректерін тазалау сақталған нәтижелерді жояды; жергілікті файл режимінде сақтау мүмкіндігі браузер баптауларына байланысты болуы мүмкін.

Жіберілген тест жауаптарын интерфейсте қайта өзгерту қарастырылмаған. Бұл сақтау тәсілі ресми емтихан нәтижелерін қорғау жүйесі болып саналмайды.

Жасанды интеллект арқылы бағалау және мұғалімнің жеке кабинеті қосылмаған. «ИИ-эксперимент» деп белгіленген бөлімдер браузердегі бағдарламалық модельдерге сүйенеді. Кеңейтілген жауаптар берілген үлгі бойынша өздігінен тексеріледі.

## Материалдарды жаңарту

Өзгерістер `index.html` ішінде жасалады. Оқу деректері `EMBEDDED_LESSONS` объектісінде, аударма логикасы `I18N` бөлігінде орналасқан. Жаңа сабақ қосқанда оның теориясын, есептерін, тестін, зертханасын, каталогтағы қолжетімділік шарттарын және маршрут нөмірлерінің шектеулерін бірге жаңарту қажет. Тек бағдарламаға тақырып қосу толық сабақ ашпайды.
